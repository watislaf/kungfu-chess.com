# Kung Fu Chess Online

Real-time multiplayer chess where both players move simultaneously - no turns, no waiting.

https://github.com/user-attachments/assets/2dcac36f-a8e5-46cd-b907-8773ee9da3c1

**Play Now**: [https://kungfu-chess.com](https://kungfu-chess.com)

## Features

- Real-time simultaneous movement
- ELO ranking system (Novice to Grandmaster)
- Quick matchmaking and private rooms
- Move cooldowns for strategic play
- Mobile-friendly design

## Quick Start

```bash
git clone https://github.com/watislaf/kungfu-chess.com.git
cd kungfu-chess.com
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to play.
