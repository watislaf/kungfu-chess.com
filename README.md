# Kung Fu Chess

Real-time chess where both players move simultaneously. No turns, no waiting.

**Play Now**: [kungfu-chess.com](https://kungfu-chess.com)

https://github.com/user-attachments/assets/2dcac36f-a8e5-46cd-b907-8773ee9da3c1

## Features

- Real-time multiplayer - move your pieces anytime
- ELO ranking system with titles from Novice to Grandmaster
- Move cooldowns to encourage tactical play
- Works on desktop and mobile

## Quick Start

```bash
git clone https://github.com/watislaf/kungfu-chess.com.git
cd kungfu-chess.com
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000) to play.

## Tech Stack

- **Frontend**: Next.js 15, TypeScript, Tailwind CSS, Socket.IO
- **Backend**: Node.js, Express, Socket.IO, AWS DynamoDB
- **Infrastructure**: AWS EC2, Terraform
